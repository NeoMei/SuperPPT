# 十风格运行资产

当前目录启用立体、玻璃、水墨、经典手绘、教材图解、创意拼贴、电影科技、奢华摄影、建筑蓝图、叙事幻想。用户按「风格 → 创意档位 → 配色」选择；配色是每种风格自身基准的相对变化，基准中线不等于黑白灰。共有 34 个可选组合、31 张精确变体预览和 10 张代表性展示图。没有现场生图选款流程。

`catalog.json` 是唯一的运行时定义源。原有立体、玻璃、水墨继续各有三个完整档位模板和三段共享色板；新增七种只公开已接受的 3 档、基准中线组合，不补造未经选样的档位或配色。模板仅有 `{{PALETTE}}`、`{{CONTENT_RELATIONSHIPS}}`、`{{SLIDE_COPY}}`，每个出现一次。调用方替换三个字段后得到完整提示词，不需要读取外部实验目录。

每种风格的 `showcase` 指向 `showcases/<styleId>.jpg`，用于第一轮选风格；`previews/<styleId>-<level>-<palette>.jpg` 是第二轮精确变体预览。两类文件均为 1280×720、500 KB 以内 JPEG，仅查看或选择它们不触发生成调用。

## 新七风格与展示来源

十张代表性展示与新增七种精确变体预览来自已接受的 `ten-style-showcase-v1`，其来源图片、提示词及 SHA-256 记录在 `provenance.json`。新增七种的模板直接从各自已接受提示词抽取：基准配色段替换为 `{{PALETTE}}`，内容关系段替换为 `{{CONTENT_RELATIONSHIPS}}`，完整可见文案块替换为 `{{SLIDE_COPY}}`；删除末尾仅适用于内部选款样例的用途说明，并将首句的「中文 PPT 广告展示页」泛化为「中文 PPT 页面」。其余画风与三档说明保持原文，创意拼贴固定采用用户接受的最初 A 版。

展示图只证明这一张样例被接受。新增七种目前只证明 3 档中线组合，不外推到其他档位、冷暖配色或任意内容的稳定性。

旧十风格的 JPEG 仍保留在 `previews/`，不在 v2 目录中，不参与当前选择与重建。它们属于历史资产，未删除或重画；旧十风格的生成定义已从构建脚本中移除。

## 验证与复建

从仓库运行 `node scripts/build-style-catalog.mjs`，验证十种风格的固定顺序、名称、档位、配色、三个槽、相对路径、溯源对应关系、JPEG 尺寸与体积，并规范化唯一目录源的 JSON 格式。再次运行内容不变；脚本不会恢复历史候选风格。

如需从保留的原图重新压缩，运行：

```sh
node scripts/build-style-catalog.mjs --normalize-previews --design-session-dir /path/to/accepted-experiment-session
```

复建旧 24 张预览时使用上面的历史实验源。复建十张展示与新增七张精确变体时运行：

```sh
node scripts/build-style-catalog.mjs --normalize-previews --accepted-source-dir /path/to/ten-style-showcase-v1
```

复建先核对清单或原图 SHA-256 与 16:9 尺寸，随后仅缩放压缩；不访问外部服务，不生成新图。两个源目录可以在同一次命令中同时提供。v0.3 八份采用模板的色板回填与限定语境清理后的逐字一致检查仍记录在溯源文件中；立体与水墨二档使用已注明的原组件组合，不伪称有一份相同的历史完整提示词。
