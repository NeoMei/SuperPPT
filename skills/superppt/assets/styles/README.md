# 已校准风格资产

当前目录只启用立体、玻璃、水墨三种风格。用户按「风格 → 创意档位 1/2/3 → 偏冷 / 基准中线 / 偏暖」选择；配色是每种风格自身基准的相对变化，基准中线不等于黑白灰。共有 27 个可选组合、24 张有对应最终色板依据的预览。没有现场生图选款流程。

`catalog.json` 是唯一的运行时定义源：每种风格有三个完整档位模板和三段共享色板。模板仅有 `{{PALETTE}}`、`{{CONTENT_RELATIONSHIPS}}`、`{{SLIDE_COPY}}`，每个出现一次。调用方替换三个字段后得到完整提示词，不需要读取外部实验目录；配色不改变档位材质，玻璃一档始终为轻薄磨砂，立体一档标题始终为平面字。

## 验证与复建

从仓库运行 `node scripts/build-style-catalog.mjs`，验证版本、风格唯一性、档位、配色、三个槽、相对路径、溯源对应关系、JPEG 尺寸与体积，并规范化唯一目录源的 JSON 格式。再次运行内容不变；脚本不会恢复旧十风格。校验允许 1–10 种风格、每种 1–3 个可用档位和数量因风格而异的非空色板集合，不把当前三风格与三色板作为未来扩展限制。

如需从保留的原图重新压缩，运行：

```sh
node scripts/build-style-catalog.mjs --normalize-previews --design-session-dir /path/to/accepted-experiment-session
```

复建先核对原图 SHA-256 与 16:9 尺寸，随后仅压缩当前 24 张预览；不访问外部服务，不生成新图。v0.3 八份采用模板的色板回填与限定语境清理后的逐字一致检查记录在溯源文件中；立体与水墨二档使用已注明的原组件组合，不伪称有一份相同的历史完整提示词。
