# 工作区

只创建新的空目录；同一 superppt-task-vnext 任务可继续。旧版本拒绝，不迁移、不清理旧任务。

superppt.json 是唯一当前状态，currentDeck 指向完整 PPTX；output/current.json 只是可重建视图。
source/original.md 保存原始内容。planning/<revision>/ 保存完整方案与选中风格。
generation/jobs/<job>/ 保存 job.json、checkpoint.json、result.json、raw/master 和 QA。
output/deck-revisions/<revision>/ 保存完整 PPTX 及页序元数据；editing/ 保存当前编辑请求。
交付/ 是最终语义文件名的位置。未确认候选不替换当前文件。

只有一个短时任务锁，外部请求和用户等待期间不持锁。
普通 JSON 原子写、文件摘要和页数检查用于中断恢复与防止拿错文件；没有签名、审计链或外部权限登记。
不要直接改写 superppt.json 来推进业务阶段，使用五个公共命令。
