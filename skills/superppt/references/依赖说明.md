# 依赖与命令说明

## 依赖边界

- `ai-image-to-ppt`：每次依赖解析都要求显式 `--ai-skill <resolved-root>`，并绑定 Skill 入口及所需脚本的完整性摘要。SuperPPT CLI 只发布计划、不可变 job、调用准入和结果接收记录；由 Agent 读取 job 并调用该 Skill，CLI 不执行 provider。
- `image-to-editable-pptx`：要求 `>=0.1.0 <0.2.0`，每次转换显式传入 `--editable-skill <resolved-root>`，输入必须是完整解码的 1280×720 PNG。
- SuperPPT 不复制、不自动安装依赖，不按模型名切换编排，不从环境变量或相邻目录发现 Skill。
- 在调用前告知用户：选中的提供者、页数、最大调用次数、出站内容（文本/参考图）和输出位置。
- 一次性 admission token 只在当次 `admit-image-call` JSON 响应中交给 Agent，并只能出现在随后的 `0600` 私有 result 输入中。不得把明文 token 写入项目 ledger、日志或其他命令输出。页面重生 request、result、route-report 和 edit-plan 均使用 `0600` 私有文件。

## CLI 路由

当前 CLI 不支持 `--help`。只用下列已实现路由，且传入每个路由要求的精确 flags：

| 用途 | 路由 |
|---|---|
| 依赖预检/项目 | `preflight --ai-skill --editable-skill`; `init --project --title`; `status --project`; `ingest --project` + 且仅一个 `--description/--text/--markdown` |
| 规划/门禁 | `validate-outline --project`; `validate-plan --project`; `publish-sample-generation-plan --project --ai-skill`; `approve --project --gate style-sample-generation`; `prepare-style-sample-job --project --ai-skill`; `finalize-style-sample --project --job-id`; `publish-style-sample --project`; `approve --project --gate <outline\|slide-specs\|style-sample\|generation-authorization>` |
| 影响/恢复 | `impact --project --change`; `approve-impact --project --sha256`; `apply-impact --project`; `rollback --project --revision`; `recover-rollback --project` |
| 生成/结果 | `publish-generation-plan --project --ai-skill --call-budget`; `approve --project --gate generation-authorization`; `prepare-deck-job --project --ai-skill`; `admit-image-call --project --job --slide --attempt --request-ordinal`; `record-image-result --project --job --result --route-report`; `prepare-page-regeneration-job --project --request`; `generation-status --project` |
| 可编辑页 | `convert-page --project --slide --ai-skill --editable-skill`; `promote-editable --project --slide --revision --element --kind`; `plan-edit --input`; `apply-edit --project --slide --revision --input`; `render-editable --project --slide --revision --record-sha256`; `confirm-preview --project --slide --revision --record-sha256 --render [--decision]`; `replace-slide --project --slide --revision --record-sha256` |
| 候选版/交付 | `assemble-candidate --project`; `publish-deck-review --project --candidate-id`; `deck-review-action --project --candidate-id --descriptor-sha256 --action <edit-page\|return-upstream\|confirm-delivery> [--slide-id]`; `acceptance --project`; `acceptance-smoke-copy --project`; `acceptance-record --project --input` |

`record-image-result` 只接收与指定不可变 job 及已准入 tuple 完全一致的私有 result，并验证串行黏性 route-report。结果必须对应当前实际 attempt，包含 required text 准确性、风格一致性、层级、丰富细节和禁用内容的 QA 结果。预览被拒绝时不得调用页面替换。

`promote-editable` 只接受已认证 conversion revision 中真实存在的 `text` 或 `asset` element ID，不修改内容、不调用 converter、不重跑 OCR/vision，也不直接发布。支持的目标返回 record SHA，仍须继续用于 `render-editable` → `confirm-preview` → `replace-slide`；未提取或 kind 不匹配的目标以 exit 0 返回单行最小 JSON `{"route":"regenerate"}`，已是 editable 的当前 modified revision 以 exit 0 返回 `{"route":"editable","status":"already-editable"}`，两者 stderr 均为空。`already-editable` 不得转成 regenerate；其他参数、认证或执行错误仍是 exit 1。

风格样张只能通过 `publish-sample-generation-plan` → 显式 execution approval → `prepare-style-sample-job` → Agent 准入/调用/结果记录 → `finalize-style-sample` 生成选定内置风格的一张代表页，并落盘 selection、包含确定性派生视觉方向的 canonical prompt input、sample 和 attempt ledger；不承诺独立 director artifact。V1 没有自定义或项目本地 recipe 路由；不要用手写 PNG 或任意 prompt 绕过 canonical proof。

`deck-review` 不得用通用 `approve` 处理，也没有独立 promotion 命令。`edit-page` 必须且只能携带一个 `--slide-id`；其他 action 禁止携带。`confirm-delivery` 同时完成对候选版 descriptor 的认证批准和交付提升。

真实客户端验收必须在插件根目录先执行 `npm run cli -- acceptance-smoke-copy --project <root>`，并且只打开返回的 `copy.path`（受控 `deck-smoke.pptx`）。绝不把 canonical `output/revisions/<n>/deck.pptx` 作为 WPS/PowerPoint smoke 文档打开或保存。客户端编辑、保存、关闭、重开后，将 descriptor path、保存后 copy SHA、客户端和观察结果写入 `0600` 私有输入，再执行 `npm run cli -- acceptance-record --project <root> --input <file>`；输入不得自报 descriptor/source SHA。
