# 依赖与命令说明

## 依赖边界

- `ai-image-to-ppt`：优先读取 `references/capabilities.json`；无 manifest 时只兼容声明的 Gemini/豆包 provider 和 Gemini reviewer 旧脚本。覆盖变量为 `SUPERPPT_AI_IMAGE_TO_PPT_SOURCE`。
- `image-to-editable-pptx`：要求 `>=0.1.0 <0.2.0`，覆盖变量为 `SUPERPPT_IMAGE_TO_EDITABLE_PPTX_SOURCE`，输入必须是完整解码的 1280×720 PNG。
- SuperPPT 不复制、不自动安装依赖，不按模型名切换编排。Capability manifest 优先于旧脚本探测。
- 在调用前告知用户：选中的提供者、页数、最大调用次数、出站内容（文本/参考图）和输出位置。
- API key 只由子进程环境继承。提示词、QA、edit-plan 用 `0600` 临时文件，子进程结束后删除；日志只记哈希和结果。

## CLI 路由

当前 CLI 不支持 `--help`。只用下列已实现路由，且传入每个路由要求的精确 flags：

| 用途 | 路由 |
|---|---|
| 依赖预检/项目 | `preflight`; `init --project --title`; `status --project`; `ingest --project` + 且仅一个 `--description/--text/--markdown` |
| 规划/门禁 | `validate-outline --project`; `validate-plan --project`; `generate-style-sample --project`; `publish-style-sample --project`; `approve --project --gate` |
| 影响/恢复 | `impact --project --change`; `approve-impact --project --sha256`; `apply-impact --project`; `rollback --project --revision`; `recover-rollback --project` |
| 生成/QA | `generate --project --concurrency`; `record-qa --project --slide --input`; `retry-page --project --slide` |
| 可编辑页 | `convert-page --project --slide`; `plan-edit --input`; `apply-edit --project --slide --revision --input`; `render-editable --project --slide --revision --record-sha256`; `confirm-preview --project --slide --revision --record-sha256 --render [--decision]`; `replace-slide --project --slide --revision --record-sha256` |
| 交付 | `assemble --project`; `acceptance --project`; `acceptance-record --project --input` |

`record-qa` 输入必须对应当前实际 attempt，包含 required text 准确性、风格一致性、层级、丰富细节和禁用内容结果。预览被拒绝时不得调用页面替换。

`generate-style-sample` 只生成选定内置风格的一张代表页，并落盘 selection、director、canonical prompt、sample 和 provider ledger。V1 没有自定义或项目本地 recipe 路由；不要用手写 PNG 或任意 prompt 绕过 canonical proof。
