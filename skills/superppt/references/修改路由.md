# 修改路由

内容、大纲或风格改变：decide 的 revise-plan，instruction 写清变更。
下一轮规划保留未改页面 ID 和规格；新 job 复用 prompt、风格、批准样页均相同且 QA 未拒绝的成功页。
换风格或改页面内容会使相关缓存失效。不再单独提出影响计划或要求影响审批。

修改某页先确定 mode（manual/agent）；用户已明确时不再重复询问。
edit 的 pageNumber 指最新完整文件中的页码，而非初始页码。
图片页需要元素修改时 route=activate-editable，只转换目标页；已有对象用 direct-edit。
重新生图使用 deck-review 的 decide action=regenerate-page，带 pageNumber、instruction、callBudget。
此路由是视觉改稿，requiredText 仍须保持；改变正文请 revise-plan。

手动候选：给完整文件链接，在 WPS/PowerPoint 保存并关闭后提交 saved-and-closed。
仅“已保存”不采纳。采纳检查页序、移动、新增、删除，直接保留用户文件字节。
Agent work：可由宿主修改候选后回传 {edited:true}；或回传 {manifestPath,operations}，对当前 OOXML 做文本、位置、样式修改。
operations 支持 replace-text、set-text-style、move-asset、move-shape、set-shape-style；换图片素材由宿主改候选并回看。
回传后展示候选完整文件，确认用 confirm-agent-edit + confirmedSha256；拒绝用 reject-edit。
不得用整套重建覆盖非目标页。当前文件在确认前不变。

rollback-deck 恢复上一个完整文件指针，不重写 PPTX。
再次修改时从新 currentDeck 与新页序创建候选。新插入的非受管页面仍可手动修改。
