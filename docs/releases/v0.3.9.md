# SuperPPT v0.3.9

本版增加可选的聊天内方案审阅，并保留所有宿主的 HTML 和普通文字路径。

- 宿主显式声明 `SUPERPPT_CHAT_INTERACTIONS=1` 后，可以在聊天中提交整体或逐页修改意见，并选择风格、创意档位和配色。
- 聊天审阅包含规划回答、可见假设、参考文件、输出位置和调用预算。方案版本与决定编号继续绑定每次回复。
- 组合卡片不展开全部候选的长提示词。Agent 在生成前展示所选组合的完整出站提示词和参考图用途，然后沿用本次授权提交，不增加第二次确认。
- 远程素材索引损坏或格式不匹配时，聊天选择继续使用文字和风格 ID。本地文件链接会编码空格、Unicode、`#` 和查询字符。

## 验收

- 源码与编译版测试各 179 项，178 通过、1 项按条件跳过。
- 类型检查、契约扫描、依赖审计、独立打包安装和版本元数据校验通过。
- 发布标签由 GitHub Actions 执行三平台检查、构建证明、校验和与公开下载。

聊天卡片需要宿主实现对应的回复能力。本轮没有重新验收真实生图、可编辑转换或各宿主的实际交互。
