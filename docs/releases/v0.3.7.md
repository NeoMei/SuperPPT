# SuperPPT v0.3.7

本版把生图授权改为默认制：确认选款即授权一次样页生图，确认样页即授权整套生成，不再在作图前单独申请授权。

- 用户选定并确认风格、档位与配色（页面复制回复或直接回复元组）后，Agent 在 plan-review 同一步披露确切样页 prompt、参考图用途、输出位置与预算 1，随即提交样页生成，不再追问授权；样页回看确认后直接生成整套。
- 选款页与确认回复文本移除“授权新增生图调用：1 次”句式和“选择风格不会授权生成”警示；页面点击与复制本身仍不发送任何请求。
- 保留的安全边界：旧方案版本或旧决定编号的回复不静默承接；未知扣费请求先澄清再继续；预算耗尽后的 retry-generation 续跑与单页付费转换仍需用户明确同意。
- 本变更属于交互契约与文案层：状态机、作业预算、prompt 快照与出站校验逻辑不变；决定 D-23 已记入规范。

本机源码与编译版测试各 170 项：169 通过、1 跳过；类型检查、契约扫描与依赖审计通过；独立打包安装冒烟在本机通过。三平台 CI 与正式发布产物以 GitHub Actions 记录为准。

本版未在真实宿主对话中端到端复测免授权作图全流程；Windows 宿主生图与 WPS／PowerPoint 编辑、保存、重新打开仍未验收。跨平台自动检查以本版本 GitHub 构建结果为准；依赖与宿主能力口径与 v0.3.6 相同。
