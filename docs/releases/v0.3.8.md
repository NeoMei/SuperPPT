# SuperPPT v0.3.8

本候选升级生图、验图和转可编辑页的模型适配，并收紧发布依赖审计。

- 生图默认模型由 ai-image-to-ppt 管理。OpenAI GPT Image 2.6 Sunburst、Gemini Nano Banana 2.1、豆包 Seedream 5.5 均支持已校验参考图。Gemini 先进行本地请求预检，再登记生图预算。
- 可选 Gemini 验图脚本默认使用 Gemini 4 Hydrogen，并过滤思考片段。逐页视觉检查由宿主实际查看图片。
- 转可编辑页默认使用 GPT-6.2 Sol 进行 OCR 与场景分析。百炼场景分析使用 Qwen4-Max JSON Mode，专用文字定位使用 Qwen3.5-OCR。
- 转可编辑页依赖修复了插件版本元数据和依赖审计。SuperPPT 将 PptxGenJS 的间接 image-size 依赖升级到已修复的 2.2.0，发布审计要求 npm audit 零漏洞。

## 已通过的验收

- SuperPPT 源码与编译版测试各 163 项，162 通过、1 跳过。类型检查、契约扫描、独立打包安装和版本校验通过。
- ai-image-to-ppt 的 Skill 校验通过，Python 测试 503 项通过、11 项跳过。
- image-to-editable-pptx 的源码与编译版测试各 523 项通过，依赖审计零漏洞。
- 本机真实宿主生图三页，覆盖参考图、图片导入、样页复用、逐页验图和 PPTX 组装。
- 独立代码评审未发现 SuperPPT 当前 main 的离线正确性阻塞项。

## 当前发布阻塞

真实可编辑转换在同一输入的多轮重试中遇到 OpenCodex `server_is_overloaded`。首次执行完成了 OCR、整页场景和一次局部场景，随后一次局部场景失败。后续重试在 OCR 阶段失败，尚未完成可编辑重组和 SuperPPT 候选接纳。

该错误来自当前上游服务，不是测试中的参数或 schema 回归。候选在上游恢复并完成同一转换前保持草稿。正式发布还需通过标签触发的 GitHub Actions 构建、校验和、构建证明及公开下载回读。

其他供应商 API 的在线可用性需在实际账号下验收。Windows 宿主生图与 Office 实机编辑保留独立验收边界。
