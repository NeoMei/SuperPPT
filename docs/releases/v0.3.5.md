# SuperPPT v0.3.5

本版改进内容呈现与使用过程，让用户先看到清晰的文字和图文关系，并在整套生成时逐页查看进度。

- 没有明确主题或资料时先引导用户提供，不假设存在 `需求.md`，不提前创建任务或检查依赖；CLI 在解析依赖与创建项目之前拒绝空白输入。
- 创意页面优先为完整文字预留阅读空间和适合风格的托底，缩小辅助图形，并要求图形表达内容含义与真实关系。样页先经过文字、语义、视觉层级和风格检查，再供用户确认；不通过时展示检查意见和样页，不自动追加生成。
- 选款页面点击风格后定位到档位和配色，选中组合显示高亮与状态，并提供文字选项回退。选择本身不授权生图：仍需将确认回复发回对话。
- 整套图片生成期间，已保存并校验的页面可以逐张展示，明确标识为尚未完成整套视觉检查的预览；仍按原预算串行生成并保留中断恢复。
- 加强参考图使用记录、样页及历史页面复用、完整图片检查、工作结果路径和任务锁恢复的校验；可编辑页面拼接遇到不能安全迁移的关系时拒绝处理，避免生成错误链接。已披露的样页提示使用原快照，升级不静默改写已确认内容。

本机源码和编译版测试各 167 项通过、1 项跳过；独立打包安装测试及本机安装后的公共 CLI 流程通过。真实立体和水墨样页用于检查文字托底及语义关系，但模型对图文面积比例的执行不保证每次一致，视觉结果仍需逐页查看。选款交互已在 Chrome 与 Codex 内置浏览器的本地服务中检查；Codex 本地文件预览的脚本执行行为尚未验证。逐页预览的数据接口与批次恢复已测试，真实 Codex 对话中的即时逐张展示尚未端到端验收。Windows 宿主生图及 WPS／PowerPoint 实际编辑、保存和重新打开尚未验收；跨平台自动检查以本版本 GitHub 构建结果为准。

已发布方案和历史样页保留其提示与状态快照；新任务应用新版内容提示与样页检查。更新运行依赖后，应按现有流程重新核对依赖快照及作业预算，不自动重复未知的请求。
