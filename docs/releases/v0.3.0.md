# SuperPPT v0.3.0

本版将完整方案回看、按需问答和十风格选择纳入同一次生成前确认，并把设计图片移至图床。通过 GitHub Release 分发，不发布到 npm。

## 主要变化

- 只追问影响叙事、内容取舍或交付范围的关键问题，一次一个；事实、偏好、假设随任务保存，恢复和修订复用已知答案。
- 任务内 HTML 展示整体叙事、逐页完整文案与来源、代表样页，以及整体和逐页修改意见；不使用浏览器时保留对话与原生图片回退。
- 保留“风格 → 档位 → 配色”，从原有三种扩展为十种内置风格，共 34 个运行组合。其余七种仅开放已接受的 3 档／中线；缺少精确预览的三个既有组合仍明确标注。
- 90 张已确认设计原图通过 imgtg 公开直链加载；安装包只含索引、文件校验信息和代码，不打包设计位图或上传凭据。图片加载失败不禁用选款。
- 页面选款不等于生图授权；确认回复绑定当前方案版本、决定编号、明确组合与一次样页预算。有修改意见时先修订，旧回复不能授权新方案。
- 确切已选提示词与实际出站文本一致。复制期间锁定意见与选款，避免异步剪贴板写入过时授权；复制失败可手动复制完整回复。
- 修复自定义样式提示词槽位校验，拒绝缺失、重复或未解析槽位进入持久化生成任务。

## 验证与边界

- 本地 main 源码、编译测试各 96 项通过、1 项预期跳过；独立打包安装测试通过，覆盖正常 3／12 页与恢复修订流程。
- 正常路径仍为三次业务决定、8 条公共命令；复用已批准样页，最终交付与批准文件字节一致。
- 本版测试使用测试图片验证流程，没有新增真实付费生图、Windows/WPS 编辑或移动端验收。
- 真实浏览器点击、剪贴板和窄视口验收受本地访问策略阻断，尚未完成；生成脚本测试不等于真实浏览器验收。
- 仍依赖独立安装的 ai-image-to-ppt 与 image-to-editable-pptx；发布不自动更新用户机器上的依赖或技能安装。
- 两项 image-size 不可达公告按既有例外接受，复查日期为 2026-10-03，不宣称零依赖漏洞。

正式产物包含插件压缩包、SHA256SUMS 和 GitHub 构建证明；跨平台 CI 与发布流水线结果可在对应 GitHub Actions 记录核对。
