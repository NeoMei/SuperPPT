# SuperPPT v0.3.4

修复豆包 API 降级时画风参考图没有实际传入的问题，并配套升级 ai-image-to-ppt 的豆包默认模型，改善中文错字。

- 样页绑定用户所选子风格的图床参考图，按哈希、字节数和尺寸校验后传入；整套生成沿用批准样页作为画风参考。
- 无参考图能力的 API 适配器返回 unavailable，不能悄悄丢弃图片；成功结果必须记录实际传入的参考图哈希。
- 配套 ai-image-to-ppt 默认使用 `doubao-seedream-5-0-pro-260628`，移除 Pro/Flash 不支持的组图参数。显式模型覆盖仍可用，不自动降回 Lite；豆包输出使用 PNG/JPEG。
- 逐页检查加入标点、重复、遗漏及标题与正文对应关系。API 成功只表示有效图片文件，不等于文字验收通过。

真实对照使用同一中文页和同一参考图：Lite 配合精简提示词仍有明显错字；Pro 配合原提示词显著改善，但遗漏部分标点；Pro 配合精简候选提示词未见明显中文错字，但构图更保守。每个条件只有一个样本，不能保证所有页面零错字。已批准提示词保持原样，不在适配器内静默简写或改动创意档位。

需要同时更新独立依赖 ai-image-to-ppt，并重新运行依赖预检。现有已确认方案、样页和成品不自动改写；重新发布方案后使用新的参考图快照。风格选择页继续使用图床 HTTPS 地址，安装包不包含风格图片二进制。
