# SuperPPT v0.2.0

macOS 优先的工作流与设计系统更新。通过 GitHub Release 分发，不发布到 npm。

## 主要变化

- 默认三次关键决定：内容方案与选款（同时授权样页）、样页回看（同时授权整套）、完整 PPTX 回看与交付；正常机器步骤连续执行。
- 移除旧 strict/audit 流水线与旧任务迁移。仅创建新的一次性任务，不修改或删除旧项目。
- 提供立体、玻璃、水墨三个已校准风格，各有三档创意和风格专属冷／中／暖配色，共 27 个组合、24 张精确预览。缺失的组合预览明确标注，不现场生成选款图。
- 风格、档位、配色快照贯穿样张、整套与重绘；完整可见文案逐字保留，图形按内容语义组织。
- 仅在生图提交边界附加实际用途与受众；不新增内容分类、预筛查、模型调用或确认轮次。该说明不是画面文字，也不是安全过滤豁免。
- 串行批次、成功页复用与预算累计继续保留；支持整套候选审阅，以及选定页面的可编辑重建和修改。
- 修复独立可编辑转换器的英寸舍入差导致拼页失败的问题；仅容忍极小尺寸舍入，仍拒绝真实尺寸或宽高比不一致。

## 边界

- 依赖 ai-image-to-ppt 和 image-to-editable-pptx 独立安装；在线能力以宿主实际可调用工具为准。
- 跨平台 CI 不代表 Windows 宿主生图或 Office GUI 编辑已验收。本次不宣称新增的 Windows 适配。
- 用途说明的降低误拒率效果未经统计验证；生图模型仍可能拒绝或画错，成品仍需查看。
- 依赖检查沿用两个 image-size 不可达漏洞的已记录例外，不宣称零依赖漏洞。

发布验收结果随本版验证记录列出，未执行的项目不作为通过。
