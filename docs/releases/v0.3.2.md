# SuperPPT v0.3.2

本版更新依赖策略：优先使用官方最新稳定版，不固定旧的插件次版本，不自动降级。

## 主要变化

- 移除 `image-to-editable-pptx 0.2.x` 门禁，接受合法稳定 SemVer，并保留包身份、实际版本和入口指纹检查；本机 0.3.0 依赖已通过启动验证。
- 安装准入不代表未来版本必然兼容。指定页转换继续检查 manifest v2、ledger v2、1280×720、单页 donor、哈希和 OOXML 对象；不兼容时报告 SuperPPT 适配缺口，而非降级或绕过检查。
- 转换准备与导入阶段增加安装变化检查，失败不切换当前 PPTX；任务进行中不自动升级插件。
- Skill、依赖说明及策略定义同步更新。CLI 仍使用明确安装路径；联网由 Agent 核实最新发布，离线不能声称已确认最新。
- 安全审计按稳定的 GHSA URL 识别原有两条例外，避免 npm 内部编号变化造成误拒绝。仍拒绝未知、重复或变更的漏洞，保留版本、不可达性和 2026-10-03 到期检查；没有移除漏洞检查或新增豁免。

## 本地验证

- 源码与编译版测试各 130 项通过、0 失败、1 项预期跳过；被跳过的独立打包安装测试已另行执行并通过。
- 类型检查、构建、完整可移植检查（含安全审计）及 v0.3.2 发布元数据检查通过。
- 审计回归覆盖编号变化、未知／重复漏洞、严重性变化、依赖链、版本、可达路径及例外过期；跨平台结果以该版本 GitHub CI 为准。

## 发布与验证边界

- 正式发布通过仓库 Release workflow 完成，提供 `superppt-0.3.2.tgz`、`SHA256SUMS` 和构建证明；不发布到 npm。
- 当前 image-size/pptxgenjs 的两项 high 报告仍存在，沿用已有不可达路径例外，不表示漏洞已修复。
- 依赖启动和自动化检查不等于付费在线转换或 WPS/PowerPoint GUI 验收；发布不会自动替换用户本机插件。
