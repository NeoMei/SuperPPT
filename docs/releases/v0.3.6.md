# SuperPPT v0.3.6

本版修正创意图形生成中对文字和图形面积的过度限制，让图形与文字共同表达内容。

- 取消固定的文字／图形面积比例及逐组强制托底，避免把创意图形压缩成背景或装饰。按所选风格与创意档位，围绕文字含义构思图形，用形态、结构和连接表达内容及真实关系。
- 适度控制单个图形的尺寸与视觉权重，为完整文字保留足够的空间、字号和对比；需要时使用与风格相符的托底。风格明确采用纯文字时，不强行添加图形。
- 样页和整套图片检查同时关注图形是否有效解释文意、关系是否准确，以及文字是否完整清晰；不因图形有表现力、未达到固定比例或没有固定托底而单独判失败。
- 已披露的样页提示和已批准的任务保留原快照，新方案使用更新后的提示与检查标准。

本机源码和编译版各 169 项通过、1 项跳过；独立打包安装测试及本机安装后的公共 CLI 流程通过。立体、水墨和玻璃风格各生成一张样页，用于检查图文关系与可读性；其中水墨样页出现原文未要求的循环箭头，说明模型仍可能生成不准确的关系。样页检查依赖实际观察，不能保证所有风格或页面均无错误。

本版尚未完成真实 Codex 对话中逐页即时展示、Codex 本地文件预览脚本、Windows 宿主生图或 WPS／PowerPoint 编辑、保存与重新打开的端到端验收；跨平台自动检查以本版本 GitHub 构建结果为准。
