# SuperPPT V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the installable SuperPPT Codex plugin that turns descriptions, pasted text, or Markdown into a confirmed high-detail image-first deck, supports versioned upstream revisions, and can replace selected slides with automatically modified editable reconstructions.

**Architecture:** SuperPPT is a TypeScript orchestration plugin with a durable project manifest, validation CLI, prompt compiler, dependency adapters, and mixed-slide deck assembler. It consumes `ai-image-to-ppt` through a capability-manifest-first adapter with a legacy Gemini/Doubao fallback, and consumes the versioned artifacts from `image-to-editable-pptx` without copying either dependency's implementation. The `superppt` Skill owns conversational planning and confirmation; deterministic scripts own schemas, hashes, path safety, invalidation, generation bookkeeping, assembly, and acceptance evidence.

**Tech Stack:** Node.js 22.6+, TypeScript 5.9, Zod 4, Sharp 0.35, PptxGenJS 4, pdf-lib 1.17, Node's built-in test runner, Python 3 with Pillow/python-pptx supplied by `ai-image-to-ppt`, Codex plugin/Skill manifests.

## Global Constraints

- Public display name is `SuperPPT`; plugin name, Skill ID, route marker, package name, and managed install directory are `superppt`.
- V1 version is `0.1.0`; `package.json` and `.codex-plugin/plugin.json` are co-authoritative and must match.
- Supported inputs are natural-language descriptions, pasted text, and Markdown files only.
- V1 deck generation is image-first; it must not claim that the whole deck is editable.
- The only ordinary human confirmation gates are outline, per-slide descriptions, and representative style sample. Upstream-impact confirmation and revised-slide preview confirmation are additional explicit mutation gates.
- Every confirmed upstream artifact remains revisable. Confirmation establishes a recoverable revision baseline, not an immutable lock.
- Style selection is single-select. V1 ships 8-12 real high-detail 16:9 previews and supports one project-local custom style.
- `ai-image-to-ppt` and `image-to-editable-pptx` remain external versioned dependencies; do not vendor, copy, or silently install their source.
- A future `gpt-image-2` provider is discovered through `ai-image-to-ppt/references/capabilities.json`; the orchestration state machine must not branch on a model name.
- Legacy `ai-image-to-ppt` installs without a capability manifest remain compatible with `scripts/gen_slide_gemini.py`, `scripts/gen_slide_doubao.py`, and `scripts/vision_check_gemini.py`.
- Editable conversion always receives an exact 1280x720 PNG. The converter's manifest v1 is the authority for editable text and reliably extracted transparent assets.
- Unsupported or unextracted objects route to page regeneration; never report them as editable.
- Every page has a stable ID independent of its current order.
- All generated and exported directories use ownership markers, canonical path checks, staging promotion, retained failed-run evidence, and immutable prior successful revisions.
- Never read, print, serialize, or pass secrets in shell command text. Child processes inherit configured environments and prompts travel through private files, not command-line arguments.
- PDF and montage are generated from the current final page-render set, including re-rendered editable pages, so they match the current PPTX revision.
- Real WPS or PowerPoint open/edit/save/close/reopen acceptance is required before completion; automated tests alone are insufficient.
- Implementation does not authorize creating a branch/worktree, publishing a marketplace, pushing GitHub, tagging, releasing, or installing globally. Request those actions separately when reached.

```ts
// src/dependencies/schemas.ts
import { z } from "zod";

export const ProviderSchema = z.object({
  id: z.string().min(1),
  module: z.string().regex(/^scripts\/[a-z0-9_-]+\.py$/),
  callable: z.literal("gen"),
  outputFormats: z.array(z.enum(["png", "jpg", "jpeg"])).min(1),
  supportsReferenceImages: z.boolean(),
}).strict();

export const AiCapabilitiesSchema = z.object({
  contractVersion: z.literal(1),
  defaultProvider: z.string().min(1),
  providers: z.array(ProviderSchema).min(1),
  reviewer: z.object({
    module: z.string().regex(/^scripts\/[a-z0-9_-]+\.py$/),
    callable: z.literal("check"),
  }).strict().nullable(),
}).strict().superRefine((value, context) => {
  if (!value.providers.some((provider) => provider.id === value.defaultProvider)) {
    context.addIssue({ code: "custom", message: "defaultProvider must name a declared provider", path: ["defaultProvider"] });
  }
});

export type ProviderCapability = z.infer<typeof ProviderSchema>;
export type AiCapabilities = z.infer<typeof AiCapabilitiesSchema>;

export type ResolvedDependencies = {
  ai: AiCapabilities & { root: string; source: "manifest" | "legacy" };
  editable: {
    root: string;
    version: string;
    cli: { cwd: string; command: "npm"; args: ["run", "cli", "--"] };
  };
};

export type PreflightReport = {
  ok: boolean;
  aiRoot: string;
  editableRoot: string;
  providers: string[];
  reviewerAvailable: boolean;
  problems: string[];
};
```

```ts
// src/dependencies/resolve.ts
import { access, readFile, realpath } from "node:fs/promises";
import { constants } from "node:fs";
import { dirname, join, resolve } from "node:path";

import { AiCapabilitiesSchema, type AiCapabilities, type ResolvedDependencies } from "./schemas.js";

async function exists(path: string): Promise<boolean> {
  try { await access(path, constants.R_OK); return true; } catch { return false; }
}

async function legacyCapabilities(root: string): Promise<AiCapabilities> {
  const providers = [];
  if (await exists(join(root, "scripts", "gen_slide_gemini.py"))) {
    providers.push({ id: "gemini-legacy", module: "scripts/gen_slide_gemini.py", callable: "gen" as const, outputFormats: ["jpg" as const], supportsReferenceImages: false });
  }
  if (await exists(join(root, "scripts", "gen_slide_doubao.py"))) {
    providers.push({ id: "doubao-legacy", module: "scripts/gen_slide_doubao.py", callable: "gen" as const, outputFormats: ["jpg" as const], supportsReferenceImages: false });
  }
  if (providers.length === 0) throw new Error("ai-image-to-ppt exposes no supported providers");
  const reviewer = await exists(join(root, "scripts", "vision_check_gemini.py"))
    ? { module: "scripts/vision_check_gemini.py", callable: "check" as const }
    : null;
  return { contractVersion: 1, defaultProvider: providers[0].id, providers, reviewer };
}

export async function resolveDependencies(options: { aiRoot: string; editableRoot: string }): Promise<ResolvedDependencies> {
  const aiRoot = await realpath(resolve(options.aiRoot));
  const editableRoot = await realpath(resolve(options.editableRoot));
  const capabilityPath = join(aiRoot, "references", "capabilities.json");
  const manifest = await exists(capabilityPath);
  const ai = manifest
    ? AiCapabilitiesSchema.parse(JSON.parse(await readFile(capabilityPath, "utf8")))
    : await legacyCapabilities(aiRoot);
  for (const provider of ai.providers) {
    if (!await exists(join(aiRoot, provider.module))) throw new Error(`provider module is missing: ${provider.module}`);
  }
  if (ai.reviewer && !await exists(join(aiRoot, ai.reviewer.module))) throw new Error(`reviewer module is missing: ${ai.reviewer.module}`);
  const pkg = JSON.parse(await readFile(join(editableRoot, "package.json"), "utf8")) as { name?: string; version?: string };
  if (pkg.name !== "image-to-editable-pptx" || !pkg.version || !/^0\.1\.\d+$/.test(pkg.version)) {
    throw new Error("a compatible image-to-editable-pptx >=0.1.0 <0.2.0 is required");
  }
  if (!await exists(join(editableRoot, "skills", "image-to-editable-pptx", "SKILL.md"))) throw new Error("editable Skill entry is missing");
  return {
    ai: { ...ai, root: aiRoot, source: manifest ? "manifest" : "legacy" },
    editable: { root: editableRoot, version: pkg.version, cli: { cwd: editableRoot, command: "npm", args: ["run", "cli", "--"] } },
  };
}

export async function resolveFromSkillEntries(options: { aiSkill: string; editableSkill: string }): Promise<ResolvedDependencies> {
  const aiEntry = await realpath(options.aiSkill);
  const editableEntry = await realpath(options.editableSkill);
  return resolveDependencies({ aiRoot: dirname(aiEntry), editableRoot: resolve(dirname(editableEntry), "..", "..") });
}
```

```ts
// src/dependencies/preflight.ts
import { access } from "node:fs/promises";
import { constants } from "node:fs";
import { join } from "node:path";
import type { PreflightReport, ResolvedDependencies } from "./schemas.js";

export async function preflightDependencies(resolved: ResolvedDependencies): Promise<PreflightReport> {
  const problems: string[] = [];
  for (const provider of resolved.ai.providers) {
    try { await access(join(resolved.ai.root, provider.module), constants.R_OK); }
    catch { problems.push(`provider module is unreadable: ${provider.module}`); }
  }
  try { await access(join(resolved.editable.root, "package-lock.json"), constants.R_OK); }
  catch { problems.push("image-to-editable-pptx package-lock.json is missing"); }
  return {
    ok: problems.length === 0,
    aiRoot: resolved.ai.root,
    editableRoot: resolved.editable.root,
    providers: resolved.ai.providers.map((provider) => provider.id),
    reviewerAvailable: resolved.ai.reviewer !== null,
    problems,
  };
}
```

```ts
// src/cli.ts
import { preflightDependencies } from "./dependencies/preflight.js";
import { resolveDependencies } from "./dependencies/resolve.js";

async function main(argv: string[]): Promise<void> {
  const command = argv[0];
  if (command !== "preflight") throw new Error("usage: superppt preflight");
  const aiRoot = process.env.SUPERPPT_AI_IMAGE_TO_PPT_SOURCE;
  const editableRoot = process.env.SUPERPPT_IMAGE_TO_EDITABLE_PPTX_SOURCE;
  if (!aiRoot || !editableRoot) throw new Error("both dependency source overrides are required by the initial CLI");
  const report = await preflightDependencies(await resolveDependencies({ aiRoot, editableRoot }));
  process.stdout.write(`${JSON.stringify(report, null, 2)}\n`);
  if (!report.ok) process.exitCode = 1;
}

main(process.argv.slice(2)).catch((error: unknown) => {
  process.stderr.write(`${error instanceof Error ? error.message : String(error)}\n`);
  process.exitCode = 1;
});
```

```ts
// src/project/paths.ts
import { lstat, realpath } from "node:fs/promises";
import { dirname, isAbsolute, parse, relative, resolve } from "node:path";

export function isSameOrAncestor(candidate: string, child: string): boolean {
  const difference = relative(candidate, child);
  return difference === "" || (!difference.startsWith("..") && !isAbsolute(difference));
}

export async function canonicalPotential(path: string): Promise<string> {
  let cursor = resolve(path); const missing: string[] = [];
  while (true) {
    try { return resolve(await realpath(cursor), ...missing.reverse()); }
    catch { const parent = dirname(cursor); if (parent === cursor) throw new Error(`Unsafe project root: ${path}`); missing.push(cursor.slice(parent.length + 1)); cursor = parent; }
  }
}

export async function validateProjectRoot(root: string): Promise<string> {
  if (!root.trim()) throw new Error("Unsafe project root: empty path");
  const canonical = await canonicalPotential(root);
  const cwd = await realpath(process.cwd());
  if (canonical === parse(canonical).root || isSameOrAncestor(canonical, cwd)) throw new Error(`Unsafe project root: ${root}`);
  try { const info = await lstat(resolve(root)); if (info.isSymbolicLink() || !info.isDirectory()) throw new Error(`Unsafe project root: ${root}`); } catch (error: any) { if (error?.code !== "ENOENT") throw error; }
  return canonical;
}
```

```ts
// src/planning/confirm.ts
import { readFile, realpath } from "node:fs/promises";
import { isAbsolute, join, relative } from "node:path";
import { readProject, sha256, writeProject } from "../project/store.js";

type PlanningGate = "outline" | "slide-specs" | "style-sample";
const previous: Record<PlanningGate, PlanningGate | null> = { outline: null, "slide-specs": "outline", "style-sample": "slide-specs" };

async function hashes(root: string, paths: string[]): Promise<Record<string, string>> {
  const canonicalRoot = await realpath(root);
  return Object.fromEntries(await Promise.all(paths.map(async (path) => {
    const canonicalPath = await realpath(path);
    const projectPath = relative(canonicalRoot, canonicalPath);
    if (!projectPath || projectPath.startsWith("..") || isAbsolute(projectPath)) throw new Error(`gate artifact is outside project: ${path}`);
    return [projectPath, sha256(await readFile(canonicalPath))];
  })));
}

export async function assertGateCurrent(root: string, gate: PlanningGate): Promise<boolean> {
  const manifest = await readProject(root); const approved = [...manifest.gates].reverse().find((item) => item.gate === gate);
  if (!approved) return false;
  for (const [projectPath, expected] of Object.entries(approved.artifactHashes)) {
    if (projectPath.startsWith("..") || isAbsolute(projectPath)) return false;
    try { if (sha256(await readFile(join(root, projectPath))) !== expected) return false; } catch { return false; }
  }
  return true;
}

export async function approveGate(root: string, gate: PlanningGate, artifactPaths: string[]): Promise<void> {
  const required = previous[gate];
  if (required && !await assertGateCurrent(root, required)) throw new Error(`${required} gate must be current`);
  const manifest = await readProject(root);
  manifest.gates.push({ gate, revisionId: manifest.currentRevision.id, artifactHashes: await hashes(root, artifactPaths), confirmedAt: new Date().toISOString() });
  await writeProject(root, manifest);
}
```

```ts
// src/revisions/impact.ts
import { createHash } from "node:crypto";
import type { ProjectManifest } from "../project/schemas.js";

export type ChangeRequest =
  | { kind: "brief"; title?: string }
  | { kind: "outline-order" }
  | { kind: "outline-structure"; slideIds: string[] }
  | { kind: "slide-spec"; slideIds: string[] }
  | { kind: "style" };
export type ImpactPlan = { baseRevisionId: string; change: ChangeRequest; staleSlideIds: string[]; invalidateExports: boolean; restartStage: ProjectManifest["stage"]; sha256: string };

export function planImpact(manifest: ProjectManifest, change: ChangeRequest): ImpactPlan {
  const all = manifest.slides.map((slide) => slide.id);
  const staleSlideIds = change.kind === "style" || change.kind === "brief" ? all
    : change.kind === "slide-spec" || change.kind === "outline-structure" ? [...new Set(change.slideIds)] : [];
  const restartStage = change.kind === "brief" ? "outline" : change.kind === "style" ? "style" : change.kind === "slide-spec" ? "slide-specs" : "outline";
  const body = { baseRevisionId: manifest.currentRevision.id, change, staleSlideIds, invalidateExports: true, restartStage };
  return { ...body, sha256: createHash("sha256").update(JSON.stringify(body)).digest("hex") };
}
```

```ts
// src/revisions/apply.ts
import { randomUUID } from "node:crypto";
import { mkdir, readFile, writeFile } from "node:fs/promises";
import { join } from "node:path";
import { ProjectManifestSchema } from "../project/schemas.js";
import { readProject, writeProject } from "../project/store.js";
import type { ChangeRequest, ImpactPlan } from "./impact.js";

async function snapshot(root: string, manifest: unknown, revisionId: string): Promise<void> {
  const directory = join(root, "revisions", revisionId); await mkdir(directory, { recursive: true });
  const path = join(directory, "superppt.json");
  const serialized = `${JSON.stringify(manifest, null, 2)}\n`;
  try {
    const existing = await readFile(path, "utf8");
    if (existing !== serialized) throw new Error(`immutable revision snapshot differs: ${revisionId}`);
  } catch (error: any) {
    if (error?.code !== "ENOENT") throw error;
    await writeFile(path, serialized, { flag: "wx", mode: 0o600 });
  }
}

export async function applyRevision(root: string, plan: ImpactPlan, change: ChangeRequest): Promise<void> {
  const manifest = await readProject(root);
  if (manifest.currentRevision.id !== plan.baseRevisionId || JSON.stringify(change) !== JSON.stringify(plan.change)) throw new Error("impact plan is stale");
  const confirmation = [...manifest.gates].reverse().find((gate) => gate.gate === "revision-impact" && gate.artifactHashes.impact === plan.sha256);
  if (!confirmation) throw new Error("revision impact must be confirmed");
  await snapshot(root, manifest, manifest.currentRevision.id);
  const next = { id: randomUUID(), number: manifest.currentRevision.number + 1, createdAt: new Date().toISOString(), parentId: manifest.currentRevision.id };
  manifest.currentRevision = next; manifest.revisions.push(next); manifest.stage = plan.restartStage;
  if (change.kind === "brief" && change.title) manifest.title = change.title;
  for (const slide of manifest.slides) if (plan.staleSlideIds.includes(slide.id)) { slide.status = "stale"; slide.staleReasons.push(change.kind); }
  manifest.exports = { pptx: null, pdf: null, montage: null, acceptance: null };
  await writeProject(root, manifest);
}

export async function rollbackToRevision(root: string, revisionId: string): Promise<void> {
  const target = ProjectManifestSchema.parse(JSON.parse(await readFile(join(root, "revisions", revisionId, "superppt.json"), "utf8")));
  const current = await readProject(root); await snapshot(root, current, current.currentRevision.id);
  await writeProject(root, target);
}
```

```python
import importlib.util

def load_module(path):
    spec = importlib.util.spec_from_file_location("superppt_external_provider", path)
    if spec is None or spec.loader is None:
        raise RuntimeError("provider module cannot be loaded")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module

def main(argv):
    if len(argv) != 6 or argv[1] not in {"generate", "review"}:
        raise SystemExit("usage: bridge <generate|review> <module> <callable> <private-input-file> <output-or-image>")
    mode, module_path, callable_name, private_path, target = argv[1:]
    private = Path(private_path)
    if private.is_symlink() or not private.is_file():
        raise RuntimeError("private input must be a regular file")
    function = getattr(load_module(module_path), callable_name)
    if mode == "generate":
        ok = bool(function(private.read_text(encoding="utf-8"), target, retries=0))
        raise SystemExit(0 if ok else 1)
    request = json.loads(private.read_text(encoding="utf-8"))
    result = function(target, request["question"])
    sys.stdout.write(result if isinstance(result, str) else json.dumps(result, ensure_ascii=False))

if __name__ == "__main__":
```

```ts
import { createHash, randomUUID } from "node:crypto";
import { execFile } from "node:child_process";
import { chmod, mkdir, readFile, rm, writeFile } from "node:fs/promises";
import { dirname, join } from "node:path";
import { promisify } from "node:util";
import sharp from "sharp";
const execFileAsync = promisify(execFile);
const hash = (value: Buffer | string) => createHash("sha256").update(value).digest("hex");

export async function generateSlide(options: { runner: string; modulePath: string; callable: "gen"; prompt: string; output: string; attempt: number; beforeExecute?: (privatePath: string) => Promise<void> }) {
  const privateDir = join(dirname(options.output), ".private"); await mkdir(privateDir, { recursive: true, mode: 0o700 });
  const promptFile = join(privateDir, `${randomUUID()}.prompt.txt`);
  await writeFile(promptFile, options.prompt, { mode: 0o600 }); await chmod(promptFile, 0o600);
  const raw = `${options.output}.${randomUUID()}.raw`;
  const started = performance.now();
  try {
    await options.beforeExecute?.(promptFile);
    await execFileAsync("python3", [options.runner, "generate", options.modulePath, options.callable, promptFile, raw], { windowsHide: true, maxBuffer: 1024 * 1024 });
    await sharp(raw).resize(1920, 1080, { fit: "cover", position: "centre" }).png().toFile(options.output);
    const outputBuffer = await readFile(options.output);
    return { promptSha256: hash(options.prompt), promptPurged: true as const, output: options.output, outputSha256: hash(outputBuffer), durationMs: Math.round(performance.now() - started), attempt: options.attempt };
  } finally {
    await Promise.all([rm(promptFile, { force: true }), rm(raw, { force: true })]);
  }
```

```ts
// src/generation/batch.ts
import type { QualityDecision } from "./schemas.js";
import { correctivePrompt } from "./quality.js";

type BatchPage = { id: string; status: "ready" | "stale" | "failed"; prompt: string; promptSha256: string; output: string };
type GenerationResult = { ok: boolean; output: string };
export async function runBatch(options: {
  pages: BatchPage[]; concurrency: number;
  generate: (page: BatchPage, attempt: number) => Promise<GenerationResult>;
  review: (page: BatchPage, attempt: number) => Promise<QualityDecision>;
}) {
  if (options.concurrency < 1 || options.concurrency > 8) throw new Error("concurrency must be between 1 and 8");
  const pages = options.pages.map((page) => ({ ...page }));
  const pending = pages.filter((page) => page.status !== "ready");
  let cursor = 0;
  await Promise.all(Array.from({ length: Math.min(options.concurrency, pending.length) }, async () => {
    while (cursor < pending.length) {
      const page = pending[cursor++]; let prompt = page.prompt; page.status = "stale";
      for (let attempt = 1; attempt <= 3; attempt++) {
        const generated = await options.generate({ ...page, prompt }, attempt);
        if (!generated.ok) continue;
        const quality = await options.review(page, attempt);
        if (quality.ok) { page.status = "ready"; break; }
        prompt = correctivePrompt(prompt, quality);
      }
      if (page.status !== "ready") page.status = "failed";
    }
  }));
  return { pages };
}
```

```ts
import { createHash } from "node:crypto";
import { AcceptanceSchema, type Acceptance } from "./schema.js";

const sha256File = async (path: string): Promise<string> => createHash("sha256").update(await readFile(path)).digest("hex");

export async function buildAcceptance(input: {
  projectId: string; revisionId: string; providerId: string; gatesCurrent: boolean;
  gateRevisionIds: { outline: string; slideSpecs: string; styleSample: string };
  pages: Array<{ id: string; order: number; mode: "image" | "editable"; status: string; finalRender: string }>;

  if (input.pages.some((page) => !["ready", "editable"].includes(page.status))) throw new Error("all pages must be ready before acceptance");
```

```ts
import { randomUUID } from "node:crypto";
import { copyFile, lstat, mkdir } from "node:fs/promises";
import { extname, join } from "node:path";
import sharp from "sharp";
import { EditPlanSchema, EditableManifestSchema, type EditableManifest, type EditPlan } from "./schemas.js";
export class UnsupportedEditableTargetError extends Error {}

export async function prepareReplacementAssets(rawPlan: unknown, revisionRoot: string): Promise<EditPlan> {
  const plan = EditPlanSchema.parse(rawPlan);
  if (plan.route === "regenerate") return plan;
  const replacements = join(revisionRoot, "assets", "replacements"); await mkdir(replacements, { recursive: true });
  for (const operation of plan.operations) {
    if (operation.kind !== "replace-asset") continue;
    const info = await lstat(operation.assetPath);
    if (info.isSymbolicLink() || !info.isFile() || extname(operation.assetPath).toLowerCase() !== ".png") throw new Error("replacement asset must be a regular PNG file");
    const metadata = await sharp(operation.assetPath).metadata();
    if (!metadata.hasAlpha) throw new Error("replacement asset must have transparency");
    const name = `${randomUUID()}.png`; await copyFile(operation.assetPath, join(replacements, name));
    operation.assetPath = `assets/replacements/${name}`;
  }
  return plan;
}

export function applyEditPlan(input: unknown, rawPlan: unknown): EditableManifest {
  const manifest = structuredClone(EditableManifestSchema.parse(input)); const plan = EditPlanSchema.parse(rawPlan);
  if (plan.route === "regenerate") throw new UnsupportedEditableTargetError(plan.reason);
  for (const operation of plan.operations) {
    const element = manifest.elements.find((candidate) => candidate.id === operation.elementId);
    if (!element) throw new UnsupportedEditableTargetError(`target is not an editable manifest element: ${operation.elementId}`);
    if (operation.kind === "replace-text") { if (element.kind !== "text") throw new UnsupportedEditableTargetError("replace-text requires a text element"); element.text = operation.text; }

    if (operation.kind === "move-asset") { if (element.kind !== "asset") throw new UnsupportedEditableTargetError("move-asset requires a transparent asset"); element.bbox = operation.bbox; }
    if (operation.kind === "replace-asset") { if (element.kind !== "asset") throw new UnsupportedEditableTargetError("replace-asset requires a transparent asset"); element.assetPath = operation.assetPath; }
  }
  return EditableManifestSchema.parse(manifest);
}
```

```ts
// src/editable/render.ts
import { readFile } from "node:fs/promises";
import { join, resolve } from "node:path";
import sharp from "sharp";
import { EditableManifestSchema, type EditableManifest } from "./schemas.js";

const xml = (value: string) => value.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;");
const color = (value: string): string => value.startsWith("#") ? value : `#${value}`;
function textSvg(element: Extract<EditableManifest["elements"][number], { kind: "text" }>): Buffer {
  const anchor = element.align === "left" ? "start" : element.align === "center" ? "middle" : "end";
  const x = element.align === "left" ? 0 : element.align === "center" ? element.bbox.width / 2 : element.bbox.width;
  const lines = element.text.split("\n"); const lineHeight = element.fontSizePx * 1.15;
  const tspans = lines.map((line, index) => `<tspan x="${x}" y="${element.fontSizePx + index * lineHeight}">${xml(line)}</tspan>`).join("");
  return Buffer.from(`<svg xmlns="http://www.w3.org/2000/svg" width="${element.bbox.width}" height="${element.bbox.height}"><text x="${x}" y="${element.fontSizePx}" text-anchor="${anchor}" fill="${xml(color(element.color))}" font-family="Microsoft YaHei,Noto Sans CJK SC,sans-serif" font-size="${element.fontSizePx}" font-weight="${element.bold ? 700 : 400}" letter-spacing="${element.charSpacingPx ?? 0}">${tspans}</text></svg>`);
}

function shapeSvg(element: Extract<EditableManifest["elements"][number], { kind: "shape" }>): Buffer {
  const { width, height } = element.bbox; const stroke = xml(color(element.strokeColor)); const fill = xml(color(element.fillColor));
  const body = element.shape === "ellipse" ? `<ellipse cx="${width / 2}" cy="${height / 2}" rx="${width / 2}" ry="${height / 2}" fill="${fill}" stroke="${stroke}" stroke-width="${element.strokeWidthPx}"/>`
    : element.shape === "line" ? `<line x1="0" y1="0" x2="${width}" y2="${height}" stroke="${stroke}" stroke-width="${element.strokeWidthPx}"/>`
    : `<rect x="0" y="0" width="${width}" height="${height}" rx="${element.shape === "roundRect" ? element.cornerRadiusPx : 0}" fill="${fill}" stroke="${stroke}" stroke-width="${element.strokeWidthPx}"/>`;
  return Buffer.from(`<svg xmlns="http://www.w3.org/2000/svg" width="${width}" height="${height}">${body}</svg>`);
}

export async function renderEditablePage(options: { root: string; manifest: unknown; output: string }): Promise<void> {
  const manifest = EditableManifestSchema.parse(options.manifest);
  const layers = [] as sharp.OverlayOptions[];
  for (const element of [...manifest.elements].sort((a, b) => a.zIndex - b.zIndex)) {
    if (element.kind === "asset") layers.push({ input: await sharp(await readFile(resolve(options.root, element.assetPath))).resize(Math.round(element.bbox.width), Math.round(element.bbox.height), { fit: "fill" }).png().toBuffer(), left: Math.round(element.bbox.x), top: Math.round(element.bbox.y) });
    if (element.kind === "shape") layers.push({ input: shapeSvg(element), left: Math.round(element.bbox.x), top: Math.round(element.bbox.y) });
    if (element.kind === "text") layers.push({ input: textSvg(element), left: Math.round(element.bbox.x), top: Math.round(element.bbox.y) });
  }
  await sharp(join(options.root, "clean-background.png")).resize(1280, 720).composite(layers).png().toFile(options.output);
}
```

````markdown
# SuperPPT

SuperPPT 把主题描述、粘贴的长文本或 Markdown 拆成经过确认的高细节图像型演示文稿，并允许把指定页面转换为可编辑的单页后替换回整套 PPTX。它不是整套全可编辑方案。

## 工作流

1. 保留原始输入，生成内容简报。
2. 展示整套页面大纲并等待第一次确认。
3. 展示逐页核心观点、文字、视觉主体、构图和关系并等待第二次确认。
4. 从紧凑风格库中单选一个风格，生成真实代表页样张并等待第三次确认。
5. 用提示词编译器生成有前景/中景/背景、材质、光线、细节、精确文字和负面约束的页面，完成 QA 后组装。

已确认内容仍可修改。SuperPPT 先显示受影响的稳定页面 ID 和导出，再局部失效、重新确认并生成新版本；旧版本可回滚。

## 风格与修改

内置 10 个真实 16:9 高细节预览，风格只能单选，也可用描述或参考图建立一个项目私有风格。文字和可靠提取的透明素材走 editable 路由；主插画、背景、整体布局或 manifest 中不存在的目标走 regenerate 路由。转换前页面统一为精确的 1280×720 PNG。

## 输出与可编辑边界

交付 PPTX、PDF、蒙太奇、项目状态、规划文件、风格配方和验收清单。普通页面是整页图片；只有经 `image-to-editable-pptx` 重建并替换的页面包含真实文本框和可靠透明素材。WPS 或 PowerPoint 打开、编辑、保存、关闭、重开后才算完成验收。

## 依赖与隐私

`ai-image-to-ppt` 和兼容版 `image-to-editable-pptx` 是外部依赖，不随 SuperPPT 捆绑或静默安装。`npm run cli -- preflight` 会验证来源和能力。模型调用前会披露提供者、页数、最大调用次数、出站文本/参考图和输出位置。API 密钥只通过环境传给子进程；提示词使用 0600 私有临时文件，日志只保留哈希。
````
