# 暗夜科技

适用：开发工具、技术架构、科技发布。

视觉预期：深蓝黑背景、清晰亮色文字，以及少量青色技术强调。低反射暗面、细边线，关键节点局部微光；文字和数据本体不发光。

本文件是原创的 PPT 化设计提案，不是从参考网页采样的品牌规范。色值和字号为待样张验证的设计默认值，不代表已通过真实生图、投影或 WPS 检查。
