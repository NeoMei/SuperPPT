# SuperPPT 九种视觉预设

状态：视觉规范提案已整理，样张未制作、未定版、未接入运行目录。当前仅增加设计文档，不修改生产代码、已有 catalog 或已安装插件。

## 产品约定

- 提供九种清晰可辨的预设，整套单选。正常制作只推荐其中 1–3 种，用户仍可要求查看全部九种。
- 保持既有三次默认决定，不新增“确认字体”“确认配色”或“确认模板分类”的门。
- 风格固定的是视觉语言，不是每页相同的构图。每份定义均包含封面、章节、正文、流程、对比、数据、总结七类变化。
- 优先验证 macOS 上的呈现与 WPS 使用，Windows 不作为本次定版的阻塞项。
- 九种是新的默认候选，不与旧十种简单叠成十九种；待样张确认后再替换默认目录。此处不执行替换，不做旧 ID 迁移。现有自定义参考能力不因候选目录变化而删除。

卡片、Bento、数据叙事虽起源于布局或表达方式，在本目录中均补齐了整套配色、字体层级和页型规则，用户不用理解分类差异。以下边界尤其需要在样张上看清：

- 通透玻璃强调半透明材质；极光渐变强调背景光晕，前景不默认玻璃化。

## 全局 PPT 规则

画布固定 16:9，建议设计基准 1920×1080，四边约 5% 安全区。静态页面，不依赖悬停、滚动、视频或动画表达必要信息。

默认使用清晰的中文无衬线字形；在 Mac 上优先考虑 PingFang SC，实际制作前确认字体可用，缺失时采用可用中文字体并保持整套一致。此处不是安装证明；图像生成提示词中的字体名也不保证生成器逐字采用真实字库。

以 13.333×7.5 英寸页面为字号参照：封面主标题通常 44–60 pt；编辑大字风可达 64–80 pt 并合理换行；正文页标题 32–40 pt，正文 20–24 pt，注释一般 14–16 pt。它们是排版起点而非额外运行门禁。内容变多时优先改分组与版式，不静默删除原文或一律缩字。

数据文字、单位与比例优先于装饰。图表可用精确渲染的图像，不要求整套改成原生可编辑图表；但不能只因生成图好看就认定数值、柱高正确。图片优先与选中页再编辑的现有路径不变。

每种风格的具体色值属于本次原创默认方案，不冒充参考网站的品牌色采样。网页仅为灵感来源；不复制品牌 Logo、产品 UI、原文或现成作品作为成品模板。

## 统一对照样张：同一内容，三种页型

仅用于模板比较的虚构演示，不代表 SuperPPT 或任何客户实测效果。九种风格均保留以下全部文字与数字。每页页脚均显示“模板演示 · 非真实业绩”。不得加入客户、品牌标识或自行追加营销内容。

### 第 1 页：封面

- 主标题：让团队把时间用在决策上
- 副标题：AI 辅助报告工作流
- 辅助说明：从素材整理，到内容编排，再到成果交付

目的：比较气质、中文标题与主视觉；不单凭这一页决定模板好坏。

### 第 2 页：正文

标题：三个环节，串起完整交付

三个信息单元，阅读顺序固定；卡片是否存在、面积是否相等由风格决定，文字不变：

1. 素材整理：汇总文档，保留关键事实。
2. 内容编排：组织观点，形成清晰层级。
3. 成果交付：检查结果，输出可用文件。

目的：比较正文可读性与分组。Bento 允许突出第 3 个交付单元，但仍用编号保留读序；极简风不强制添加卡片。

### 第 3 页：数据

标题：单份报告处理时间从 48 分钟降至 24 分钟

同一张纵向柱图，所有预设顺序、单位、刻度一致：

| 阶段 | 时间（分钟） |
|---|---:|
| 原流程 | 48 |
| 试用期 | 32 |
| 稳定期 | 24 |

- 纵轴：时间（分钟），从 0 起，范围 0–60，间隔 20。
- 每根柱顶显示实际值；稳定期为强调系列。
- 辅助结论：每份减少 24 分钟，处理时间缩短 50%。
- 来源说明：虚构演示数据，仅用于模板对照。

目的：比较信息承载与图表清晰度。不能改变柱高比例、隐藏基线或把示例数据写成已证明的效率收益。

## 样张和定版方式

九种风格分别制作上述三页，共 27 个页面，这是模板库的一次性设计工作，不是每次用户做 PPT 都付出 27 页成本。本轮没有执行这些生成调用。

第一屏用紧凑九宫格浏览，每张风格卡使用同一正文页作为主缩略图并标注名称；点开或展开才看该风格的封面、正文、数据三页及原尺寸图。不要用不同内容或不同页型当各风格的主缩略图。

定版只看四件事：九种是否足够可辨；中文和数字是否清楚；三种页型是否都成立；整套是否统一而不机械重复。未达标的风格调整自己的规则与样张，不扩大确认流程。

这些仍是待验证的描述，不是假装已经生成的预览。实际样张制作的工具、调用上限及费用须在执行前明确；当前不启动付费或外部生成。
