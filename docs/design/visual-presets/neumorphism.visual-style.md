# 柔光浮雕

适用：管理汇报、产品能力、服务方案。

视觉预期：同色表面的柔和浮雕，深色文字与克制蓝色强调。哑光同色表面，左上浅高光与右下软阴影；装饰柔和，文字对比鲜明。

本文件是原创的 PPT 化设计提案，不是从参考网页采样的品牌规范。色值和字号为待样张验证的设计默认值，不代表已通过真实生图、投影或 WPS 检查。
