# 模块卡片

适用：能力清单、案例合集、并列方案。

视觉预期：等权模块清晰分组，适合并列事实与可扫描的信息。实色浅卡片、细边框或极浅投影；统一圆角，不使用玻璃或厚浮雕。

本文件是原创的 PPT 化设计提案，不是从参考网页采样的品牌规范。色值和字号为待样张验证的设计默认值，不代表已通过真实生图、投影或 WPS 检查。
