# 三套商务风格排版与档位

三套风格依次为深海智汇、商务青瓷、数据看板，排在原十种风格前。每套三档创意 × 冷、中、暖配色，共九张参考图；代表图复用三档中线。

正文以文字为主，使用独立左对齐标题、明确字号层级与留白。图形服务语义图标与真实的信息关系；仅输入包含统计数据时使用数据图表或 KPI，不编造数据。正文无流光、光晕、大幅插画或装饰性场景。流光仅在明确的封面需求下克制使用。

2026-09-14 档位修正：用户指出原三档几乎相同。原因是共享提示词强制左侧三组图文、右侧两个数字，档位只调整圆底和连接线。此前的图片加载与文字校验没有覆盖档位可辨识性。

- 一档：文字简报，用规整要点、短段落或比较表传达信息；数字保留在原句，不使用图标和关系路径。
- 二档：图文分区，语义小图标配合正文，独立突出重点或有依据的数据；沿用已认可的左右主次结构。
- 三档：关系信息图，以流程、层级、对比等真实关系重组整页，文字直接与节点、图标和路径结合。不能只给二档添加连接线。

这些是通用生产规则，不固定五组亮点、节点数或流程方向。内部示例继续逐字采用 style-showcase-copy.md 的 SuperPPT 文案；其中“10 大精选模板”保持已确认文案，不改为 13。
