## 当前状态

- 已实现：10 种内置风格。立体／玻璃／水墨各有三档创意与偏冷／基准中线／偏暖；新增七种仅有已接受的 3 档／基准中线，共 34 个可选组合、31 张精确组合预览和 10 张代表展示图；已选组合贯穿样页和整套。
- 已实现：完整文案进入提示词；样页和正式页提交时附加真实用途；无修改且通过检查的已批准样页按原位置复用。
- 已实现：规划上下文保存当前事实、偏好、假设和叙事摘要；中断恢复与方案修订继承上下文，已发布方案将上下文固化到当前 revision。
- 已实现、待真实交互验收：方案发布时生成任务内 HTML，展示整体方案、逐页完整文案／来源／修改意见、全部十种风格和所选风格的现有档位 × 配色；当前版本、decisionId、确切样页 prompt、参考用途、输出位置和预算 1 绑定同一快照。旧版本授权不能创建新方案作业，纯对话与原生图片回退保持可用。浏览器点击、剪贴板、窄视口和手机呈现尚未实测。
- 资产缺口：立体一档中线、玻璃一档偏冷、玻璃二档偏冷没有最终配色精确预览；可选但须说明，不自动生图补齐。
- 本轮本地候选：十风格目录、完整方案确认页和三次业务决定公共流程已经接入源码、编译产物与独立打包安装检查；本版未新增真实生图宿主验收，也不要求所有风格拥有相同数量的档位或色板。
- 平台边界：macOS 优先；自动化可移植检查不等于 Windows 宿主生图或 Office 编辑验收。

## 后续如何保持可查

后续需求发生变化时，在对应 spec 更新当前规则，并在决定记录追加简短的「诉求 → 决定 → 替代项 → 实现／样例依据」。没有实现或没有视觉验收的部分继续明确标注；无需为每次调整另建审批流程或大型审计台账。
