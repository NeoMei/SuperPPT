## 当前状态

- 已实现：立体／玻璃／水墨，三档创意，各风格偏冷／基准中线／偏暖；27 个可选组合、24 张精确组合预览；已选组合贯穿样页和整套。
- 已实现：完整文案进入提示词；样页和正式页提交时附加真实用途；无修改且通过检查的已批准样页按原位置复用。
- 已确认、待落实：两轮选款——先一次展示全部当前可用风格，再一次展示所选风格的档位 × 配色组合。当前仅有选项数据和顺序约定，尚无完整呈现与交互验收证据。
- 资产缺口：立体一档中线、玻璃一档偏冷、玻璃二档偏冷没有最终配色精确预览；可选但须说明，不自动生图补齐。
- 本轮新增目标：从三风格补齐到十风格，并将选款图统一改为 SuperPPT 亮点介绍。共用短文案已确认，清单与制作范围见[展示页文案](style-showcase-copy.md)；新图和新增七风格尚未实现，不要求所有风格拥有同样数量的色板。
- 平台边界：macOS 优先；自动化可移植检查不等于 Windows 宿主生图或 Office 编辑验收。

## 后续如何保持可查

后续需求发生变化时，在对应 spec 更新当前规则，并在决定记录追加简短的「诉求 → 决定 → 替代项 → 实现／样例依据」。没有实现或没有视觉验收的部分继续明确标注；无需为每次调整另建审批流程或大型审计台账。
