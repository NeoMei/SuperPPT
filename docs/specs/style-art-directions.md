## 新增七风格：固定画法，不固定题材

| 风格 | 已确认画风描述 |
| --- | --- |
| 经典手绘 | 钢笔淡彩手绘画风，略有自然抖动的轮廓线、少量排线与轻薄水彩铺色；像精心绘制的设计手稿，不做儿童涂鸦或杂乱草稿。 |
| 教材图解 | 现代教材信息插画画风，轻纸感底面、清晰无衬线文字、圆润二维图形、友好手绘小图标与简洁承载面；平面、亲和、规整，不使用摄影或立体渲染。 |
| 先锋瑞士 | 瑞士现代主义平面海报画风，粗体无衬线字、非对称网格、纯色几何形与利落切割；强调字号和空间对比，不靠纹理、渐变或投影制造效果。 |
| 电影科技 | 科幻电影概念设计画风，精密工业形体、真实空间透视、克制的体积光与发光细节；避免满屏 HUD、代码雨和无意义科技线条。 |
| 奢华摄影 | 高端品牌静物摄影画风，真实材质、精确布光、细腻明暗与克制景深，搭配精致编辑排版；不靠金色、珠宝或奢侈品符号堆出高级感。 |
| 建筑蓝图 | 建筑设计图纸画风，精确细线、明确线宽层级、轴测／剖面表达与少量透明色面；画出内容关系，不添加无来源尺寸或装饰性标注。 |
| 叙事幻想 | 超现实叙事插画画风，细腻数字绘画、柔和笔触、可信光影与不寻常的尺度组合；用巧妙场景表达含义，不固定城堡、童话或魔法题材。 |

总数仍为 10：上述七种加立体、玻璃、水墨。经典手绘、教材图解替换上一版候选中的科学图鉴、电影编辑；它们不是新增为 12 种。历史三维微缩仍不独立占位。

## 教材图解的默认样式来源

来源为已安装 `ai-image-to-ppt/SKILL.md` 的 `Prompt style`，于 2026-09-06 核对。该技能提供的是一个默认样式块，不是十风格目录。下方保留来源快照，供教材图解的基准方向使用；不是给所有 SuperPPT 风格附加的通用规则。

```text
Style: 16:9 educational textbook infographic slide.
Background: soft warm cream off-white (#f8f5f0), subtle paper-like texture.
Typography: clean modern Chinese sans-serif (Noto Sans / Inter), dark navy-charcoal.
Accent: terracotta orange (#e67e22); friendly hand-drawn icons and rounded cards.
Layout: generous whitespace; no dark edge banners, photos, neon, gradients, or 3D.
```

这套暖米白／深色字／陶土橙是教材图解的来源基准，不是所有风格的固定配色。其后续冷暖变体与三档表达须看样例，不能宣称依赖已经提供或验证这些组合。原技能的「恰好八卡片、两列四行」是另一个数量控制示例，不是默认画风，不带入五组亮点文案。

## 新七种的档位与配色边界

- 画风固定绘画语言、材质、线条与光影；档位改变文字主导、局部融合、大胆视觉叙事的表达强度，不能以换画风代替升档。
- 平面画风高档仍可保持平面，通过更巧妙的语义结构增强创意，不必变成立体。手绘强调自然笔触，教材图解强调规整的信息组织，不能仅靠颜色区分二者。
- 配色按风格选择；背景、主体和构图随内容设计。建筑蓝图不必蓝底，奢华摄影不必黑金，叙事幻想不必城堡。
- 使用共用亮点文案，不删改文字；标题独立统一。先制作方向样例，再决定档位和适合的色板，不能把画风文字定义视为模型稳定性证明。
